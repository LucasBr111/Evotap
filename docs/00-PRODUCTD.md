# EVOTAP — Product Overview

## 1. Vision
EVOTAP is a modular, multi-tenant SaaS platform that connects physical NFC/QR media with dynamic, highly-configurable digital experiences.

## 2. Core Value Proposition
- Instant hardware-to-digital mapping via secure public code resolution.
- Dynamic destination management managed internally by EVOTAP operators.
- Fast, privacy-focused interactions requiring zero friction for end-users scanning physical media.

## 3. Product Offerings (MVP Commercial Tiers)
While all offerings run on a unified infrastructure, they represent three commercial execution modes:

1. **Review**:
   - Physical NFC/QR routes directly to a controlled Google Reviews external URL.
   - Ideal for single-action conversion and review collection.
2. **Business**:
   - Renders a lightweight, high-performance landing page using structured templates (`GENERAL`, `FOOD`, `HEALTH`).
   - Displays core business info, links, actions, and essential brand details.
3. **Web NFC**:
   - Advanced Business Page utilizing expanded template modules (e.g., dynamic catalog/menu, services list, enhanced action components).

## 4. Operational Model
EVOTAP operates under an internal-managed model in MVP. Clients do NOT self-manage their tags or pages via a self-service dashboard. All provisioning, tag assignments, page creation, and lifecycle transitions are performed by EVOTAP staff through the internal `/admin` workspace.
